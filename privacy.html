Privacy policy

Market Brief · Last updated 26 October 2026

What this app does

Market Brief is a private automation that uploads one market report video a day to its owner's own YouTube channel. It uses the YouTube Data API with a single permission, youtube.upload, which lets it upload videos to that channel.

Data we access

The app is used only by its owner. It accesses only the owner's own YouTube account, and only to upload videos and set their title, description and thumbnail. It does not read, collect or store data about any other person, viewer or YouTube user.

How data is stored

The only stored item is the owner's Google sign-in token, kept as an encrypted secret in the owner's private GitHub repository so the daily upload can run. It is never shared, sold or sent anywhere except to Google's own APIs.

Google API Services

Market Brief's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.
